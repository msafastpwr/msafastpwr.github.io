# MSA FAST Peshawar website

Plain HTML, CSS and JavaScript. No build step, no frameworks. Hosted on GitHub Pages: every merge to `main` goes live automatically.

## Run locally
The site uses root-absolute paths (`/assets/...`) and `fetch()`, so open it through a local server, not by double-clicking a file.

This folder (the one that contains `index.html`) must be the Git repository root. Do not `git init` in a parent folder such as Downloads, or a push will include unrelated files.

- VS Code: install the **Live Server** extension, right-click `index.html` -> *Open with Live Server*
- or, with Python installed: `python -m http.server 5500` in the repo folder, then open `http://localhost:5500`

## Structure
```
index.html               Home 
about/ events/ team/     one folder per section: index.html, <section>.css, <section>.js
blog/ contact/ join/     (home's css/js live in home/)
data/                    events.json, team.json, blog.json  (shared data contracts below)
images/<section>/        each owner puts images only in their own folder
images/shared/           logo 
assets/                  LOCKED: theme.css, components.css, site.js
docs/                    CONTRIBUTING.md, TASKS.md, CLAUDE_PROMPT.md
.github/                 LOCKED: CODEOWNERS, PR template
```

## Locked files (lead AND co-lead approval)
`assets/css/theme.css`, `assets/css/components.css`, `assets/js/site.js`, `404.html`, `.github/*`, `images/shared/*`. Every PR in this repo needs approval from both the lead and the co-lead.
The header and footer are generated by `site.js`, so nobody edits them in their pages.

## Shared data contracts (do not rename fields)
Dates are `YYYY-MM-DD`. Empty string means "not set": your code must handle that (e.g. no image).

- `data/events.json`: `[{ title, date, time, location, summary, image, link }]`  (owner: Events; Home reads it)
- `data/team.json`: `[{ name, role, group, photo, linkedin, github }]`  (owner: Team; `group` is `leadership` or `member`)
- `data/blog.json`: `[{ title, date, author, summary, image, url }]`  (owner: Blog; Home reads it)
